### 📦 StockSense — Modular Inventory Management System

A full-stack inventory management application designed to centralize stock operations across multiple warehouse facilities.

**Highlights:**

- 🔐 User authentication with bcrypt
- 👥 Inventory Manager and Warehouse Staff roles
- 🔑 OTP-based password recovery
- 📊 Real-time inventory dashboard
- 📈 Live KPI cards and inventory valuation
- 🔎 Multi-dimensional inventory filtering
- 🏭 Warehouse and location management
- 📦 Stock movement tracking
- 🔄 Internal transfer management
- 📋 Inventory activity monitoring
- 🧪 Automated API/E2E testing

**Tech Stack:**

`React` `TypeScript` `Vite` `Tailwind CSS`  
`Node.js` `Express.js` `SQLite` `JWT` `bcryptjs`

🔗 [View StockSense](https://github.com/Divyakrish-007/stocksense)
